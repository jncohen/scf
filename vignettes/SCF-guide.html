Analyzing the Survey of Consumer Finances

Introduction

The Survey of Consumer Finances (SCF) is a triennial survey of U.S. household finances conducted by the Federal Reserve Board. It is among the most detailed data sources on U.S. household wealth, income, and financial behavior. Valid estimation from the SCF requires handling two design features:

  1. Survey design: the SCF uses a dual-frame sample with 999 bootstrap replicate weights, which are used to estimate sampling variance.
  2. Multiple imputation: the SCF fills in missing answers five times, giving five implicates. Each is a complete version of the data with different filled-in values.

The scf package handles both. It wraps the five implicates in replicate-weighted survey::svrepdesign() objects, runs each estimate in every implicate, and pools the results. See ?scf_variance for how standard errors are computed.

Throughout, the unit of analysis is the SCF’s primary economic unit: the person or couple at the economic center of the household and everyone financially dependent on them. The Fed calls this unit a “family”; this package calls it a household.

This vignette demonstrates the core workflow. It runs on the package’s mock data, a small sample of the 2022 survey, so the numbers shown are not estimates for the population; the same code runs on the full data. For methodological background, see the package paper listed under Learn More.

Workflow

1. Downloading and Loading the Data

Download SCF data and load it into a multiply-imputed survey object using scf_download() and scf_load().

scf_download(2022)
scf2022 <- scf_load(2022)

The result is a scf_mi_survey object containing five svyrep.design objects, one per implicate, and survey-year metadata. The package covers every wave from 1989 to 2025; scf_download(2025) fetches the latest. Each object records the dollar year of the Fed’s summary variables (see Dollar values below):

scf2022
#> SCF Multiply-Imputed Survey Object
#> ----------------------------------
#> Year:           2022
#> Households (N): 5,793,387
#> Implicates:     5
#> Replicate weights per implicate: 999 
#> Dollar year:    2022
scf2022$dollar_year
#> [1] 2022

2. Creating and Transforming Variables

scf_update() adds or modifies variables uniformly across all five implicates. Bottom-code skewed variables before logging to avoid log(0).

scf2022 <- scf_update(scf2022,
  senior       = age >= 65,
  female       = factor(hhsex, levels = 1:2, labels = c("Male", "Female")),
  rich         = networth > 1e6,
  networth     = ifelse(networth > 1, networth, 1),
  log_networth = log(networth),
  income       = ifelse(income > 1, income, 1),
  log_income   = log(income)
)

Use names(scf2022$mi_design[[1]]$variables) to inspect available variables.

When a transformation depends on the distribution within each implicate, such as ranks, percentile flags, or group z-scores, use scf_update_by_implicate() instead:

scf2022 <- scf_update_by_implicate(scf2022, function(df) {
  df$wealth_rank <- rank(df$networth) / nrow(df)
  df
})

scf_subset() keeps the households that meet a condition, in every implicate. Estimates from a subset describe that group alone; to compare groups, use by in the estimating functions instead.

seniors <- scf_subset(scf2022, age >= 65)
scf_median(seniors, ~networth)
#> Multiply-Imputed Median Estimate
#> 
#>  variable quantile estimate       se    min    max  n
#>  networth      0.5   179890 67650.09 152800 211350 54

Dollar values

Summary variables made by the Fed, such as income, networth, and asset, are in the dollars of one year in every survey year: 2025 for files downloaded since October 2026, 2022 before that. scf_load() records this as dollar_year. Raw survey variables, named x followed by a number, are in dollars of the survey year. Before comparing a raw variable across years, or combining it with summary variables, convert it with scf_real(). List income items, which are reported for the year before the survey, in income:

scf2016 <- scf_real(scf2016, ~x5702 + x3915, income = ~x5702)

To report a result in dollars of the survey year, as in the Fed’s nominal-dollar tables, use scf_nominal() on the result. Both functions stop with an error if given the wrong kind of variable, unless force = TRUE.

6. Quantile Regression

OLS models the conditional mean, which is sensitive to outliers and skew. Wealth and income distributions in the SCF are highly right-skewed: a small number of high-wealth households can dominate mean estimates. Quantile regression estimates the conditional quantile of the outcome at a user-specified probability tau. Estimating several quantiles shows how a predictor’s effect differs across the distribution.

scf_quantreg() fits quantreg::rq() with SCF final sampling weights to each implicate, then pools coefficients and variance-covariance matrices across implicates via scf_MIcombine().

# Median regression
m_med <- scf_quantreg(scf2022, log_networth ~ age + senior, tau = 0.50)
print(m_med)
#> Quantile Regression Results (tau = 0.50, Multiply-Imputed SCF)
#> ------------------------------------------------------------------
#>         term estimate std.error t.value   p.value stars
#>  (Intercept)   8.2337    0.8347  9.8646 < 2.2e-16   ***
#>          age   0.0772    0.0168  4.6051 4.161e-06   ***

The se argument controls within-implicate variance estimation. All methods feed a covariance matrix into scf_MIcombine(), so between-implicate (imputation) variance is always incorporated.

  • "replicate" (default): re-fits the model with each of the SCF’s 999 replicate weights in each implicate, via survey::withReplicates(). The variance is the spread of the replicate coefficients around their mean, as the Fed computes it. This is the only method that uses the SCF’s sample design. It refits the model about 5,000 times, so it can take several minutes on the full data.
  • "nid": non-iid sandwich estimator. Allows the conditional sparsity (the density of the error distribution at the quantile) to vary across observations.
  • "iid": the Koenker-Bassett (1978) covariance formula, which assumes the error distribution is the same for all observations. Fastest option.
  • "ker": kernel density estimate of the conditional sparsity.
  • "boot": pairs bootstrap.

The last four come from quantreg::summary.rq() and treat the weighted sample as a simple random sample, so they ignore the SCF’s design. They are useful for quick exploration; report results with "replicate".

# Fast standard errors while exploring
m_quick <- scf_quantreg(scf2022, log_networth ~ age + senior,
                        tau = 0.50, se = "nid")

A note on design: the survey package provides svyquantile() for estimating marginal quantiles of a single variable, but it has no function for regression quantiles (conditional quantiles given covariates). scf_quantreg() therefore uses quantreg::rq() for point estimation, with survey::withReplicates() providing the design-based variance wrapper for the "replicate" path.

Koenker and Bassett (1978) established the asymptotic theory for the unweighted, i.i.d. case. Applying rq() with survey sampling weights extends the estimator to probability-weighted samples, which is standard empirical practice; the "iid" and "nid" standard error formulas extend correspondingly to the weighted design matrix X'WX. The "replicate" option sidesteps this by using the SCF’s own replication scheme to estimate variance directly, without relying on distributional assumptions about the errors.

To study how associations vary across the outcome distribution, estimate the same model at multiple quantiles and compare:

taus <- c(0.25, 0.50, 0.75, 0.90)
models <- lapply(taus, function(t) {
  scf_quantreg(scf2022, log_networth ~ age + senior, tau = t)
})
names(models) <- paste0("tau=", taus)
do.call(scf_regtable, c(models, list(digits = 3)))
